# Code of conduct

zest_ssh_core adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, for everyone who takes part: in issues, pull requests, discussions, reviews,
and any other place the project is represented.

In short:

- Be respectful and assume good faith, including when you disagree.
- Critique code and ideas, not people.
- No harassment, insults, personal attacks, or unwelcome sexual attention, and no publishing
  anyone's private information without their permission.

## Reporting

Report behavior that breaks this code to **support@zestssh.com**, with "Code of conduct" in the
subject. Reports are read by the maintainer and kept confidential. Where a report is about the
maintainer, it goes to the same address and is handled by Affluent Labs LLC, which owns the project
(see [GOVERNANCE.md](GOVERNANCE.md)).

## Enforcement

The maintainer may edit or remove comments, commits, issues and pull requests that break this code,
and may warn, or temporarily or permanently ban, anyone who does, following the enforcement
guidelines of the Contributor Covenant 2.1: correction, warning, temporary ban, permanent ban.
